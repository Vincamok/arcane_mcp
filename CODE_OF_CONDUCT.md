# Code of Conduct

We want this project to be a welcoming, harassment-free space for everyone.

## Expected behavior

- Be respectful and constructive; criticize ideas, not people.
- Welcome newcomers and assume good faith.
- Accept feedback gracefully and focus on what is best for the project.

## Unacceptable behavior

- Harassment, discrimination, insults, threats or personal attacks.
- Publishing others' private information (including credentials) without permission.
- Spam, trolling, or any conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Maintainers may edit or remove comments, issues, pull requests and other contributions that violate this code, and may temporarily or permanently ban contributors.
To report a violation, use GitHub's private reporting (**Security › Report a vulnerability**) or the **Report content** feature of GitHub. Reports are treated confidentially.

This policy is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
