# Support

- **Bug or feature request**: open a GitHub issue using the templates.
- **Question / usage help**: read the README first, then open an issue labeled `question`.
- **Security vulnerability**: do not open an issue; see [SECURITY.md](SECURITY.md).

This is a community project maintained on a best-effort basis, without any SLA.
For problems with Arcane itself, use the Arcane project's own channels.
